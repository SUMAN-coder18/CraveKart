# CraveKart — Food ordering website

A responsive front-end food ordering demo built with plain HTML, CSS and JavaScript.

## Run it
1. Extract `CraveKart-website.zip`.
2. Open `index.html` in a browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension.

## Features
- Responsive landing page and food menu
- Category filters, live search and sorting
- Add-to-cart, quantity controls and cart persistence with localStorage
- Delivery fee calculation and demo `YUM10` coupon
- Checkout form with demo order confirmation
- Newsletter interaction demo

## Important
This is a front-end demonstration only. Checkout does not send orders to a restaurant, process payments, validate delivery addresses, or store customer details on a server. A production system needs a backend/API, database, authentication, secure payment gateway integration, order management and delivery integration. Product photos are loaded from Unsplash and Google Fonts are loaded online.
